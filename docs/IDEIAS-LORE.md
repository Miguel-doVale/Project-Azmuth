# Ideias de lore (Ben 10) para o Azmuth

Pesquisa feita em 2026-10-09 no ben10.fandom.com (wikitext pela API do MediaWiki).
São ideias, não decisões; marcadas com a dificuldade estimada.

## Fatos de cânone mais úteis
- **Cores do core = modos:** verde ativo · vermelho recarga (pisca no Alien Force) · amarelo
  coleta/scan · azul reconfiguração · roxo controle de terceiros/ameaça temporal · laranja
  autodestruição ou criação de espécie · cinza inativo · rosa feitiço · branco transformado (clássico).
- **Timeout:** 10 min no clássico, 15 min no Omniverse. Recarga instantânea quando a vida
  do usuário corre perigo; no Omniverse, failsafe transforma no alien necessário.
- **Destransformar na mão** evita o timeout e permite transformar de novo mais rápido.
- **Trocas em excesso sobrecarregam** o relógio ("I could sense it half a galaxy away").
- **Master Control** liberado por código ou pela voz do Azmuth.
- **Comandos de voz:** "Omnitrix Voicecommand Mode", "Access Master Control", autodestruição
  "Command code: 000 - Destruct - 0", desacoplar "000 - Release Coupling - 0"; Ultimatrix
  "Abort Self Destruct Code 10", "Ultimatrix Reset Code 10"; Omniverse "Command Code 1010
  Tennyson Benjamin Disengage Life-Form Lock".
- **Ultimatrix:** reset segurando o símbolo 2 s; modo radiação (bipa e pisca vermelho); função
  evolutiva com quatro espinhos e bateria esgotando mais rápido.
- **Scan de DNA:** novas espécies vão para a "playlist ativa"; disco com silhuetas pretas
  (clássico) ou hologramas verdes (Alien Force).
- **Omniverse:** chamadas, modo emergência (choque que fura o bloqueio), lanterna, trava de usuário.
- **Galvan:** tecnocracia em Galvan Prime; invenções marcadas com a ampulheta verde. O idioma
  falado são grunhidos com tradutor embutido; **não há escrita Galvan no cânone** — as runas do
  Azmuth são invenção própria e não conflitam.
- **Outros:** distintivo dos Encanadores (mapa, comunicador, tradutor, detector de radiação),
  Codon Stream/Primus (~1.000.910 DNAs), Unitrix, Proto-Tool, Nemetrix (hexagonal, vermelho e prata).

## Ideias (dificuldade)
1. Código de cores completo do core: amarelo scan, azul atualização, roxo SSH, cinza ocioso,
   laranja desligamento agendado, rosa Não perturbe (baixa).
2. Scan amarelo de app novo via hook do pacman → playlist (média).
3. Recalibração azul durante `pacman -Syu`/kernel: não transforma (média).
4. Autodestruição = desligamento agendado com contagem laranja; "code 10" aborta (baixa).
5. Modo de comando de voz com as frases do cânone; voz real com Vosk/Whisper depois (média/alta).
6. Failsafe: bateria crítica/temperatura alta → DNA de sobrevivência mesmo na recarga (média).
7. Reset Mode: segurar o Omnitrix 2 s recarrega a shell (baixa).
8. Destransformar manual recompensado com recarga mais rápida (baixa).
9. Sobrecarga: muitas trocas por minuto → glitch e bloqueio curto (baixa).
10. Life-Form Lock: trava um DNA sem timeout ("1010 … Disengage") (baixa).
11. Modo Radiação: vermelho piscando em throttling térmico ou Wi-Fi inseguro (baixa).
12. Nível Ultimate com quatro espinhos e descarga 2–3× mais rápida (média).
13. Codex: base de dados de DNAs com estatísticas e silhuetas (baixa/média).
14. HUD com estilo silhueta (clássico) ou holograma (AF) (baixa).
15. Modo emergência: crítico fura o Não perturbe com tremida/flash (baixa).
16. Widget Distintivo dos Encanadores: celular (KDE Connect), Bluetooth, rede (média).
17. Codon Stream/Primus: DNAs como rio verde; backup/sync dos dotfiles via git (média).
18. Erros com a voz sarcástica do Azmuth ("Pathetic workmanship") (baixa).
19. Skin Albedo/Nemetrix para o Kali Core (média).
20. Lanterna: tela branca e brilho máximo (baixa).

## Funções sugeridas para os 9 aliens
- **XLR8:** performance (governor, animações zeradas, barra que "fecha o visor").
- **Quatro Braços:** build pesado (layout 2×2, compilação paralela, Docker, monitor de núcleos).
- **Diamante:** integridade (snapshots btrfs/Timeshift, verificação de backup).
- **Besta:** foco sem visual (sem barra e pop-ups; avisos só por som).
- **Fantasmático:** privacidade (VPN/Tor, câmera e microfone desligados, janelas translúcidas).
- **Aquático:** mídia imersiva; fora da tomada, a energia cai mais rápido.
- **Insectoide:** visão geral (Constelação padrão; "gosma" fixa janelas em todos os workspaces).
- **Ultra-T:** automação (scripts, CI, dispositivos; bordas de circuito nas janelas).
- **Chama:** gaming/render (gamemode, GPU no máximo; superaquecimento → failsafe).
