# Ilha do Omnitrix + Dock — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a barra de cima por uma ilha retrátil do Omnitrix (repouso → mouse → painel; fio com app maximizado) e uma dock central sempre recolhida, mais apps que abrem maximizados, saída de som automática e serviços do systemd na aba Inicialização.

**Architecture:** Configuração nova em `settings.json` (Python, `src/core.py`) exportada no `theme.json` que a shell já lê. Regras do Hyprland geradas em Python e enviadas com `hyprctl eval` (mesmo padrão de `src/display.py`). Interface em Quickshell/QML: `Island.qml` (janela + fases) com `IslandPanel.qml` (conteúdo da fase 3) e `Dock.qml`, substituindo `Bar.qml` e `Dashboard.qml` no `shell.qml`.

**Tech Stack:** Python 3 (unittest), Quickshell/QML (Quickshell.Hyprland, .Services.Mpris, .Services.Pipewire, .Services.SystemTray, .Bluetooth, .Wayland), Hyprland 0.56 (config Lua), PipeWire/pipewire-pulse.

**Spec:** `docs/superpowers/specs/2026-11-14-ilha-dock-design.md` · referência visual e de comportamento com tamanhos reais: `docs/design/prototipo-ilha-dock.html` (v3) — copiar medidas, tempos e curvas de lá.

## Global Constraints

- **Não commitar.** O Miguel faz os próprios commits; cada tarefa termina num checkpoint listando os arquivos mudados.
- Screenshots só no **workspace 9 vazio** (trocar com `hyprctl dispatch workspace 9`, capturar com `grim`, voltar ao workspace anterior). Nunca digitar/registrar a sequência do bloqueio.
- Testes Python: `.venv/bin/python -m unittest discover -s tests` (todos precisam passar ao fim de cada tarefa).
- Shell: depois de editar QML, o Quickshell recarrega sozinho; conferir o log mais recente em `/run/user/1000/quickshell/by-id/*/log.qslog` (`strings … | grep -i error`) — zero erros novos.
- Hyprland: regras de monitor/janela via `hyprctl eval 'hl.…'`; regex é RE2 (escapar `.` como `\\.` dentro da string Lua); `hyprctl reload` apaga regras de runtime → `azmuth restore` reaplica.
- Medidas (px reais): repouso Omnitrix Ø44 com ~16 px visíveis; fase 2 = 420×64; painel = 728×458; fio = 140×3; ilha solta a 10 px do topo; ícones da dock 48 px; risquinho 24×3 por workspace.
- Tempos: transição de forma 550 ms `cubic-bezier(.22,1,.36,1)` (QML: `Easing.Bezier` com `[0.22,1,0.36,1,1,1]`); fase 2 recolhe após 350 ms fora; fio abre após 300 ms parado na zona; dock desce 450 ms após o mouse sair.
- Cores e fontes só de `Colors`/`theme` (DNA ativo); Orbitron para títulos/números, Rajdhani para texto.
- `exclusiveZone: 0` em ilha e dock; a máscara de entrada (`mask: Region`) acompanha só o que está visível.

## Review Focus

- **Projetor/segundo monitor ligado:** ilha e dock aparecem só no monitor em foco (`targetScreen()`) e o fio reage ao app maximizado *daquele* monitor → Task 5, Step 6 (com o projetor/HDMI conectado, ou conferindo que existe uma única instância de `Island`).
- **DNA com `bar.visible: false`:** a ilha continua igual e a dock não aparece → Task 5, Step 3 e Task 8, Step 1.
- **Nenhum player tocando / player sem capa ou sem duração:** quadrado mostra "nada tocando", barra de tempo escondida e sem arrastar → Task 7, Step 5.
- **Workspaces especiais** (`special:minimized`, `special:magic`) nunca aparecem no risquinho nem na faixa; workspace vazio atual aparece só na faixa → Task 8, Step 5.
- **App aberto sem `.desktop`/sem ícone** (ex.: janela do próprio Quickshell, apps AppImage) → ícone genérico, nunca vazio → Task 8, Step 5.
- **Lista `windows.maximize` com classe inválida ou com caracteres de regex** (`org.kde.dolphin`, `foo(bar`) → escapada, sem quebrar o Hyprland → Task 2, testes.
